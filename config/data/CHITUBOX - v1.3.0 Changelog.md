# 简体中文

**新增功能**

- **自由切割：**在模型表面自由绘制切割路径，闭合形成切割面，并能灵活调节路径锚点，使切割结果更符合期望；
    
- **封装模型：**将多个模型封装成单一对象，可为封装后的对象生成包围盒；
    
- **模型对齐：**通过面对齐/线对齐，快速将两个模型旋转放置到理想位置；
    
- **功能面板快捷键：**功能面板现已为常用按钮添加快键键显示与触发；
    
- **对话窗口快捷键：**可通过键盘快速触发对话窗口命令按钮；
    
- **顶部功能栏快捷键：**短按alt键，临时显示顶部功能栏全部快捷键；
    
- **商城ChituNest：**一站式打印周边补给站；
    

**改进**

- **模型布局模式：**现在导入、复制、镜像模型都可应用“在当前平台居中”、“应用自动布局”、“保留原始世界坐标”；
    
- **对象旋转：**旋转模型时，按住shift键，将按45°的角度进行旋转；按住shift+ctrl键，将按15°的角度进行旋转；
    
- **平台菜单：**新增展开/收起全部选项；
    
- **材料参数配置：**现在可以批量删除材料参数；
    
- **修复：**高级修复改为模型修复的子项；
    
- **快捷键：**新增3d视图控制快捷键；
    
- **自定义面板布局：**可根据日常使用习惯，设置面板布局为左右双面板、单面板（合并至右侧）、单面板（合并至左侧）；
    
- **ChituAction：**齿科工作区下，所有应用可选配置扩展至3个；
    
- 优化了模型与对象列表交互体验；
    
- 优化了镜像支撑检测精度；
    
- 优化了布尔操作性能；
    
- 优化了缩略图分辨率；
    
- 新增.prz与.goo格式桌面预览；
    
- 新增打印机：Phrozen Sonic Mighty Revo 16K Max、ELEGOO Jupiter 2；
    

**修复**

- 修复了自动支撑重复添加的问题；
    
- 修复了模型重叠无法全部框选的问题；
    
- 修复了布尔操作结果错误的问题；
    
- 修复了部分底筏添加异常的问题；
    
- 修复了一些已知bug；
    

# 繁体中文

**新增功能**

- **自由切割**：支援在模型表面自由繪製切割路徑，閉合後即可形成切割面，並可靈活調節路徑錨點，使切割結果更精確符合預期；
    
- **封裝模型**：可將多個模型封裝為單一對象，並為封裝後的對象生成包圍盒（Bounding Box）；
    
- **模型對齊**：透過「面對齊」或「線對齊」功能，快速將兩個模型旋轉並放置到理想位置；
    
- **功能面板快捷鍵**：功能面板中的常用按鈕現已支援快捷鍵顯示與觸發；
    
- **對話視窗快捷鍵**：支援透過鍵盤快速觸發對話視窗中的命令按鈕；
    
- **頂部功能列快捷鍵**：短按 Alt 鍵即可臨時顯示頂部功能列的所有快捷鍵提示；
    
- **商城 ChituNest**：一站式 3D 列印周邊補給站正式上線；
    

**改進**

- **模型佈局模式**：導入、複製、鏡像模型時，現可選擇應用「在當前平台居中」、「應用自動佈局」或「保留原始世界坐標」；
    
- **對象旋轉**：旋轉模型時，按住 Shift 鍵將以 45° 為增量旋轉；按住 Shift + Ctrl 鍵則以 15° 為增量旋轉；
    
- **平台菜單**：新增「展開/收起全部」選項；
    
- **材料參數配置**：支援批量刪除材料參數；
    
- **修復功能優化**：「高級修復」已調整為「模型修復」的子項目；
    
- **快捷鍵更新**：新增 3D 視圖控制快捷鍵；
    
- **自定義面板佈局**：可根據使用習慣設置面板為「左右雙面板」、「單面板（合併至右側）」或「單面板（合併至左側）」；
    
- **ChituAction**：在齒科工作區下，所有應用的可選配置擴展至 3 個；
    
- 優化了模型與對象列表的交互體驗；
    
- 優化了鏡像支撐的檢測精度；
    
- 優化了布林運算（Boolean）的操作性能；
    
- 提升了縮略圖解析度；
    
- 新增 .prz 與 .goo 格式的桌面預覽支援；
    
- 新增印表機：Phrozen Sonic Mighty Revo 16K Max、ELEGOO Jupiter 2；
    

**修復**

- 修復了自動支撐重複添加的問題；
    
- 修復了模型重疊時無法全部框選的問題；
    
- 修復了布林運算結果錯誤的問題；
    
- 修復了部分底筏（Raft）添加異常的問題；
    
- 修復了一些已知bug；
    

# 英文

**New Features**

- **Free Cutting**: Draw custom cutting paths directly on the model surface to create closed cutting planes. Anchor points can be adjusted flexibly for more precise results;
    
- **Combine Models**: Encapsulate multiple models into a single object and generate a bounding box for the encapsulated group;
    
- **Model Alignment**: Quickly rotate and position two models using "Face Alignment" or "Line Alignment" tools;
    
- **Panel Shortcuts**: Common buttons in the functional panels now support shortcut display and triggering;
    
- **Dialog Shortcuts**: Command buttons within dialog windows can now be triggered quickly via keyboard shortcuts;
    
- **Toolbar Shortcuts**: Briefly press the "Alt" key to temporarily display all shortcuts for the top toolbar;
    
- **ChituNest**: Your one-stop shop for 3D printing supplies and accessories;
    

**Improvements**

- **Model Layout Strategy**: "Center on Platform," "Auto Layout," and "Preserve Original World Coordinates" can now be applied when importing, duplicating and mirroring models;
    
- **Object Rotation**: When rotating models, hold "Shift" to snap to 45° increments; hold "Shift + Ctrl" to snap to 15° increments;
    
- **Platform Menu**: Added "Expand/Collapse All" options;
    
- **Material Profiles**: Support for batch deleting material parameters;
    
- **Repair Function**: "Advanced Repair" is now moved as a sub-item under "Model Repair."
    
- **Shortcuts**: Added new shortcuts for 3D view control;
    
- **Custom Panel Layout**: Users can now configure the layout as "Dual Panels (Left & Right)," "Single Panel (Merged to Right)," or "Single Panel (Merged to Left)."
    
- **ChituAction**: In the Dental Workspace, the optional configurations for all applications have been expanded to three;
    
- Optimized the interaction experience for the Model and Object lists;
    
- Enhanced the detection precision for mirrored supports;
    
- Optimized the performance of Boolean operations;
    
- Improved thumbnail resolution;
    
- Added desktop preview support for .prz and .goo formats;
    
- Added new printers: Phrozen Sonic Mighty Revo 16K Max, ELEGOO Jupiter 2;
    

**Bug Fixes**

- Fixed an issue where automatic supports were being added repeatedly;
    
- Fixed an issue where overlapping models could not be fully selected using box selection;
    
- Fixed an error in the results of certain Boolean operations;
    
- Fixed an issue where rafts were generated incorrectly in some cases;
    
- Fixed various known bugs;
