# CHITUBOX Changelog 写作风格

基于 Raycast Changelog 骨架，融入 CHITUBOX 品牌调性调整而成。

---

## 一、基本规则（继承自 Raycast）

### 语调
- 专业友好，像懂产品的同事在跟你聊天，不是官腔公告。
- 用「我们」指代团队，用「你/您」直接对用户说话，营造对话感。
- 对功能有热情但克制，不夸张、不营销腔。**CHITUBOX 比 Raycast 略暖一度**，可以在导语里用「来啦」、英文里用 "finally here" 这类轻度兴奋表达。

### 结构
1. **导语段落（1-3 句）**：用对话式语气介绍本版本头条功能，说明解决了什么问题。
2. **三语发布**：每个版本必须包含 简体中文 / 繁體中文 / English 三个区块，以 `---` 分隔。
3. **三段式分类**：每个语言区块内，条目归入三个固定板块：

| 简体中文 | 繁體中文 | English |
|---|---|---|
| `## 新增功能` | `## 新增功能` | `## New Features` |
| `## 改进` | `## 改進` | `## Improvements` |
| `## 修复` | `## 修復` | `## Fixes` |

> 注意：不使用 emoji 标题（与 Raycast 的 `## ✨ New` 不同），用纯中文/英文文字。

### 条目格式
- `- **组件名**：描述`（中文用全角冒号 `：`，英文用半角冒号 `: `）
- 每条一行，不换行，不加句号/分号。
- 电报式简洁——删到只剩必要语义，但不牺牲完整性。

### 语态与时态
- 主动语态：新增 / 支持 / 修复 / 优化 / 提升 开头。
- 现在时态：描述当前版本的行为。
- 英文同理：Added / Improved / Fixed / Support for... 开头。

### 标记规范
- **代码/键位/格式名**：用反引号，如 `Shift`、`Alt`、`.prz`、`.goo`
- **UI 文案/设置项名**：中文用双引号 `""`（简中）或直角引号 `「」`（繁中），英文用双引号 `""`
- **组件名前加粗+冒号**：`**打印平台**：` ——每个条目必须有组件标签
- **补充说明**：用斜体 _Note_ / _注意_ 开头（极少使用）

### 用语统一
- 不用「bug」，用「问题」/「問題」/「issue」
- 不用「fix 了 bug」，用「修复了...的问题」/「修復了...的問題」/「Fixed an issue where...」
- 不用句号 `。` 收尾条目（导语段落例外）

---

## 二、CHITUBOX 特有规则

### 品牌表达
- 产品名统一为 `CHITUBOX`（全大写，不在中文里加「赤兔」等音译）。
- 首次提及时可用全称，后续统一用 `CHITUBOX`。
- 功能名称如 `ChituNest`、`ChituAction` 保留原文大小写，不翻译。

### 简中 vs 繁中
- **简体中文**：第二人称用「您」（正式、礼貌），引号用 `""`，中文冒号 `：`
- **繁體中文**：第二人称用「你」（港台惯例），引号用 `「」`，中文冒号 `：`

### 英文版
- 英文导语可以比简中更活泼一点（如 "finally here!"、"We're bringing you..."）
- 标题使用 `## New Features` / `## Improvements` / `## Fixes`（不用 emoji）
- 条目末尾不加标点

### 条目中未挂组件名的处理
原文里有些条目不带组件前缀（如「优化了布尔操作性能」），润色时必须根据语义提取一个恰当的组件标签，例如：
- 「优化了布尔操作性能」→ `**布尔操作**：优化了布尔操作性能`
- 「提升了缩略图分辨率」→ `**缩略图**：提升了缩略图分辨率`

## 三、完整示例（简体中文片段）

```
# 简体中文

CHITUBOX v1.3.0 来啦！这次我们带来了自由切割、模型封装和快速对齐，让您在处理复杂模型时更加得心应手。功能面板和对话框全面开放快捷键支持，ChituNest 严选商城同步上线，一站式满足您的耗材购买需求。

## 新增功能

- **自由切割**：在模型表面自由绘制切割路径，闭合形成切割面，锚点可灵活调节
- **封装模型**：将多个模型封装为单一对象，并为其生成包围盒
- **商城 ChituNest**：一站式打印周边补给站正式上线

## 改进

- **模型布局模式**：导入、复制、镜像模型时均可应用"在当前平台居中"、"应用自动布局"、"保留原始世界坐标"
- **对象旋转**：按住 `Shift` 以 45° 增量旋转，按住 `Shift + Ctrl` 以 15° 增量旋转
- **布尔操作**：优化了布尔操作性能

## 修复

- **自动支撑**：修复了支撑重复添加的问题
- **框选**：修复了模型重叠时无法全部框选的问题
- **稳定性**：修复了一些已知问题
```

## 四、快速自检清单

生成/润色 changelog 后，逐项核对：

- [ ] 三语区块是否齐全（简中 / 繁中 / English）
- [ ] 板块标题是否为纯文字（不是 emoji）
- [ ] 简中用 `""` 和 `：`，繁中用 `「」` 和 `：`，英文用 `"` 和 `:`
- [ ] 简中第二人称是否用「您」
- [ ] 每条是否一行、不加句号/分号
- [ ] 每条是否有组件名前缀 `**组件名**：`
- [ ] 全文是否无 `bug` 字样（用 `issue` / `问题`）
- [ ] 产品名、功能名大小写是否正确
