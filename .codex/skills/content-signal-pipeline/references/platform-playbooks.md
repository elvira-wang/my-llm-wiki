# Platform Playbooks

## Reddit

Use Reddit when the user asks for r/chitubox, r/resinprinting, r/ElegooMars, r/PrintedWarhammer, weekly hot threads, community posts, or source-backed discussion prompts.

### Positioning

- Be a knowledgeable peer, not a brand megaphone.
- Lead with a real community problem, useful observation, or testable checklist.
- Mention CHITUBOX only where it naturally helps the workflow.
- Invite correction and parameter sharing.

### Strong Reddit Forms

- **Case breakdown**: "A user thought X was the issue; the thread points to Y."
- **Myth check**: "AA can help pixel texture, but it will not erase Z stepping."
- **Diagnostic checklist**: "Before changing 8 settings, check these 5 variables."
- **Question-led field note**: "How do you decide when a hollow model is worth the risk?"
- **Community roundup**: "This week's recurring resin-printing failures and what they have in common."

### Reddit Package Requirements

- Suggested subreddit(s).
- Post title options, with one recommended title.
- Opening paragraph in plain community language.
- Main body with bullets or short sections.
- Sources: raw thread paths and Reddit URLs.
- Evidence labels for each claim.
- Optional image/screenshot list.
- Comment-seeding questions to encourage replies.
- Risk notes: what could be challenged by the community.

### Avoid

- Corporate launch language.
- Claims like "the best slicer" unless sourced and framed as opinion.
- Using Reddit only as a traffic source.
- Posting a definitive answer when the thread shows unresolved debate.

## Discord

Use Discord when the user asks for server programming, recurring columns, community activities, help channels, weekly prompts, events, or moderation-friendly engagement.

### Strong Discord Forms

- **Weekly troubleshooting clinic**: one failure type, one checklist, users share photos/settings.
- **Before/after gallery prompt**: users post failed print and fixed print.
- **Parameter swap thread**: resin/printer/profile comparison with a required template.
- **Office-hours topic**: live discussion around one mechanism.
- **FAQ seed**: turn repeated questions into a pinned answer draft.

### Discord Package Requirements

- Channel/category suggestion.
- Recurring cadence.
- Host prompt.
- Participation template users can copy.
- Moderator notes and safety reminders.
- Wiki/raw links for host prep.
- Follow-up archive plan: what should be converted into wiki/digest later.

### Avoid

- Overly long posts that kill conversation.
- Prompts that require users to reveal unsafe behavior without safety framing.
- Asking broad questions like "Any tips?" without a template.

## Short Video

Use short video when the user asks for TikTok, YouTube Shorts, Reels, Bilibili short content, hooks, scripts, or visual demonstrations.

### Strong Short-Video Forms

- **One mistake, one mechanism, one fix**.
- **Before/after** with screenshots or printed parts.
- **3-step diagnostic** shown on slicer screen.
- **Myth bust** with a visual counterexample.
- **Comment-to-video**: answer a community question from Reddit/Discord.

### Short-Video Package Requirements

- Platform and target duration.
- Hook options for the first 2 seconds.
- Script with visual beats.
- Shot/material list.
- On-screen text.
- B-roll/screen recording needs.
- Source list and claim confidence.
- Cutdown variants.

### Avoid

- Explaining five mechanisms in one short.
- Showing unsafe resin handling.
- Using tiny text that cannot be read on mobile.
- Making the product UI the whole story when the audience pain is the hook.
