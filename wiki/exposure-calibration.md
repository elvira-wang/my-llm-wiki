# 曝光校准

确定你的树脂 + 打印机 + 层高组合下，普通层最佳曝光时间的测试过程。

**什么时候必须做**：每次换新树脂（品牌、颜色、类型）。Dream Reich："每瓶树脂都做。" [^2]

底层曝光是独立流程，参见 [[bottom-exposure|底层曝光]]。

**前置条件**：确保 [[temperature-control|树脂温度]] ≥ 25°C——低温下测出的曝光值无效。确保 [[build-plate-leveling|平台已调平]]。

---

## 过曝与欠曝的通用现象

不管用什么测试模型，打印件上的现象指向同一个方向。先学会读现象，再选工具。

### 过曝（曝光时间太长）

| 现象 | 为什么 |
|---|---|
| 细节模糊、边缘变圆 | 紫外光散射到目标区域之外 → 额外固化 |
| 孔/槽变小或封闭 | 超过设计尺寸的固化填充了空隙 |
| 支撑触点粗大、拆除困难 | 支撑周围的树脂也被部分固化 |
| 尺寸偏大 | 每层固化范围超出设计轮廓 |
| 测试模型上"应该失败的"部分成功了 | 过度固化掩盖了设计意图的差异 |

### 欠曝（曝光时间太短）

| 现象 | 为什么 |
|---|---|
| 层间分离（分层/开裂） | 前一层未充分固化 → 与后一层附着不足 |
| 模型细节模糊、表面发粘 | 树脂未完全固化 → 物理强度不足 |
| 模型从支撑上脱落 | 支撑与模型的连接点固化不足 |
| 薄壁/细柱不成型或断裂 | 截面太小 → 所需曝光不足 → 未固化完全 |
| 尺寸偏小 | 边缘区域固化不充分 → 未达到设计轮廓 |

### 判断口诀

> 表面糊、孔变小、支撑难拆 → **降曝光**（每步 0.2-0.3s）
> 层分离、细节碎、模型掉 → **升曝光**（每步 0.2-0.3s）

## 调整步进

| 偏差程度 | 调整量 | 示例 |
|---|---|---|
| 明显过/欠（失败面的锥出了大半 / 分层严重） | 0.3-0.5s | 2.5s → 2.0s |
| 接近目标（仅边缘问题 / 仅最后 1-2 个锥） | 0.1-0.2s | 2.1s → 1.9s |

Okay Hobby Time 的实战案例：第一次 Cones of Calibration 失败 → "我做了一次小调整（0.2s），重新打印，通过了。" [^3]

**灰色树脂通常比透明/彩色需要更短的曝光**——颜料影响 UV 穿透深度。从灰色开始校准，换颜色时以此为基准微调。

## 测试模型

测试模型是将通用现象可视化的工具。选哪个不重要——看懂现象才重要。

### Cones of Calibration

TableFlip Foundry 免费发布。分为成功面（标有 "Success"）和失败面（标有 "Failure"）。

- **成功面**：所有锥形柱必须完整打印、互相连接。有锥断开 → 欠曝。
- **失败面**：所有锥必须完全不出。出任何一个（哪怕只有前面 1-2 个）→ 过曝。

> Dream Reich 提醒："很多时候失败面只出了最前面一两个小锥，大家觉得差不多可以了。不可以——只要失败面出了锥，你的曝光就太高。继续降，直到完全不出。"

Dream Reich 配合使用了一个 L 形扳手测试件——扳手必须刚好插入模型槽中，不松不紧。这是对尺寸精度的物理验证：插不进 → 过曝、松旷 → 欠曝。[^2]

预计耗时约 40 分钟，消耗约 13g 树脂。

### Ameralabs Town

综合测试：文字清晰度、桥接长度、细柱阵列、棋盘格。适合对多个维度同时评估——不只是"成不成"，还有细节是否锐利。

### XP2 Validation Matrix

单次快速判断。看细节还原度——适合有经验后快速验证。

## 常见误判

| 误判 | 实际情况 |
|---|---|
| "默认参数应该差不多" | 每台机器的 LCD 光强都不同——"即使同一型号，光强也不一样" [^2] |
| "同品牌同颜色的树脂不用重测" | "同一品牌同颜色的不同批次，曝光可能有差异" [^2] |
| "测试件过了，大模型一定没问题" | 反过来验证一次——测试件通过后用熟悉的大模型打一遍确认 |
