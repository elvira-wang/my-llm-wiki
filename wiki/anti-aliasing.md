# 抗锯齿

## 定义

通过对切片边缘像素施加不完全曝光，使固化边缘从"一刀切"的直角台阶变为渐进的柔和过渡，从而改善 [[pixel-texture|像素纹]]。

**前置知识**：[[pixel-texture|像素纹]]（抗锯齿要解决的对象）、[[screen-bit-depth|屏幕色深]]（抗锯齿效果的硬件上限）。

**下位概念**：[[grayscale-threshold-testing|灰度阈值测试]]（灰度抗锯齿的参数校准流程）。

---

## 两种实现方式：不同的原理，同一个目标

目标一致——让每层模型的边缘不完全固化，形成"半固化"过渡区，与邻近区域融合以填补阶梯间隙。

### 方式 1：抗锯齿级别（闪烁抗锯齿）

早期方案。部分 DLP 光机与旧 LCD 屏幕一个像素只有**开/关**两种状态（不支持灰度显示）。通过在同一层内使用多张不同切图交替曝光，减少边缘像素的总曝光时间来模拟"不完全固化"。

可用级别：**2、4、8**。关键规律（反直觉）：**级别越高 → 单张切图的曝光时间越长 → 固化程度越高 → 边缘越锐利 → 抗锯齿效果反而越弱。**[^1]

兼容格式：早期 `.cbddlp`。**现在绝大部分 LCD 机器不支持此方式。**

### 方式 2：灰度级别 + 模糊范围（当前主流）

切片边缘生成灰色过渡像素，灰色像素降低光源穿透强度 → 树脂不完全固化 → 形成柔和边缘。

**灰度级别**：
- 范围 0-255（0 = 黑色 = 不透光，255 = 白色 = 全透光）
- 左侧红框 = 最低允许灰度，右侧红框 = 最高允许灰度
- 灰度越低 → 透光率越低 → 固化程度越低。**低于某一阈值后树脂完全不固化**——这个阈值就是"最低有效固化灰度"，需要 [[grayscale-threshold-testing|测试确定]]

**模糊范围**：
- 可用值：2-8。在切片边缘**内外两侧**继续生成灰色像素
- 值越高 → 生成灰色像素越多 → 过渡越柔和 → 抗锯齿越强 → 但模型细节损失也越多
- 相当于 Photoshop 中的"羽化"。Zack.俞师傅的描述："模糊范围……相比灰度级别会较大影响模型细节（变肉、变糊、不够锐利），重点表现在微缩模型、小字、纹理等" [^1]

## 参数建议

### Dennys Wang 的实测

打印机 Phrozen Sonic Mini 4K，层高 0.03mm，切片软件 CHITUBOX。[^2]

| 设置 | 效果 |
|---|---|
| **AA 0 + Image Blur 2** | "最平衡——保留细节同时消除体素纹" |
| AA 0 + Image Blur 4 | 体素几乎完全消失，细节损失可接受 |
| AA 4 + Image Blur 2 | 伪影增多，体素纹仍可见 |
| AA 关闭 | 体素纹和伪影最明显 |

> **注意**：这是 2021 年在一台 Sonic Mini 4K 上的结果。你的打印机分辨率不同、树脂不同——结论可能不同。不要直接套用参数，参考他的方法用自己的打印机测。

### 通用建议

1. 先确认你的打印机支持哪种 AA 方式——"绝大部分 LCD 机器仅支持灰度级别 + 模糊范围" [^1]
2. 先开灰度级别（不开启模糊范围），测试效果
3. 单开灰度仍有明显像素纹 → 再逐步开启模糊范围 2 → 4 → 6
4. 在"改善像素纹"和"模型细节"之间找平衡点——**"模糊范围增加更多灰色像素，会较大影响模型细节" [^1]**

## 注意事项（多条来自同一来源 [^1]）

### 尺寸膨胀

AA 会向外增加像素 → 模型尺寸轻微变大。打印配合精度要求高的件时**谨慎开启**或使用尺寸补偿功能。

### 预支撑模型的格式陷阱

打印 `.stl` / `.obj` 格式的预支撑模型时，切片软件无法区分支撑和模型本体 → **支撑也被一起抗锯齿** → 支撑触点尺寸改变 → 可能断裂或留下更大的疤痕。

**解决方案**：使用 `.chitubox` 或 `.ctp` 工程格式——软件可以区分支撑和模型，支撑不会被 AA 影响。

### 文件大小

开启 AA 后计算量增大 → 切片速度变慢 + 文件大小显著增加。部分 FAT32 格式老机型使用闪烁抗锯齿时单个切片文件不能超过 4GB。

### 参数依赖

- 确保**提前测定曝光参数**——曝光是 AA 的基础。先校准曝光，再调 AA
- 更换树脂、机器或改变层高 → 重新测试 AA 参数

### 适用性

本文结论基于 CHITUBOX 的算法逻辑。不同切片软件的设计原理存在差异——内容不保证对其他软件的普遍适用性。[^1]
