# 零件连接方法

## 定义

打印多零件模型时，将零件可靠地连接在一起的各类设计技术。覆盖从最简单的胶粘到利用 3D 打印独有几何能力实现的锁定机构。

本文以 Slant 3D 的完整分类 [^1] 为主要依据，他们是量产级 3D 打印服务商——这些方法是经过大批量生产验证的，不是个人偏好。

**前置知识**：[[free-cutting|自由切割]]（切割 + 连接是天然搭档）。[[tolerance-and-fit|公差设计]]（连接结构和公差配合密切相关）。

---

## 为什么需要设计连接

胶水是最简单的方案——但纯胶粘依赖表面粘附力，在受力方向或长期使用中容易失效。设计物理连接结构让零件互锁，减少对胶水的依赖，同时提供**可复现的装配精度**——每次组装结果一致。

---

## 方式一览

### 菱形销钉 (Diamond Peg)

最简单的物理连接方式。核心洞察：**不要用圆形销钉。**

"圆形孔会下垂，尺寸偏差大。圆形销钉水平打印时层间易折断。把方形销钉转 45° 变成菱形——没有悬空、尺寸精确、销钉在打印方向上强度最大。" [^1]

| 优势 | 局限 |
|---|---|
| 设计极简 | 仅靠摩擦力固定——无锁定机制 |
| 尺寸精确（菱形孔无悬空） | 大面积零件可能有缝隙——零件可弹性变形导致间隙 |
| 强度好（不在层线方向上受力） | |

### 板槽连接 (Slab & Slot)

薄壁零件边缘的低矮型连接。关键细节："把插入端（slab）做成渐窄的锥形，让它滑进去时越来越紧——配合 3D 打印层纹的天然摩擦力，锁得很牢。" [^1]

### S 型卡扣 (S-Bracket)

对称结构——在零件上设计一个孔，滑入 S 形连接件，连接件卡入对面的槽中。可通过改变连接件厚度调节夹紧力。

"非常简单但极其可靠。可以做成随意厚度来增加强度。非常精确的接合——只要你能接受零件上有个孔。" [^1]

### C 型卡扣 (C-Clamp)

双侧 C 形夹，压入槽中卡住。比 S 型更直观（"不需要学习怎么用" [^1]），但可靠性略低——C 型结构依赖弹性变形，设计不当会松脱。

### T 型槽 (T-Slot)

标准 T 型舌槽——提供横向支撑力，拉不开。问题：多公差叠加 + 复杂首层 → 制造一致性不稳定。

### 弹簧 T 槽 (Spring T-Slot)

T 型槽的升级——将两侧外翼做成弧形 → 它们像弹簧一样弯进去卡住。**"零间隙、零晃动、完美的紧缝。"** [^1]

关键设计细节：将槽做成倾斜角度 → 首层是简单的方形（无复杂几何）→ 复杂结构推迟到打印后期 → 避免首层翘曲。Slant 3D 评价："只要这个底面不是外观面，这是最可靠的方式之一。"

### I 型槽 (I-Slot)

用圆形法兰代替 T 形——**设计最简单**（只需一个圆和另一个圆对齐尺寸），**对首层友好**（全是圆角、无尖角→低翘曲风险）。局限：和所有舌槽一样，可能有顶部分离导致间隙。

### 抓鳍 (Grip Fins)

环绕孔内壁的一系列柔性小片。"无法用 3D 打印之外的任何工艺制造——内部凹槽不可能加工或注塑。" [^1]

通过改变抓鳍的厚度和长度来控制夹持力。I 型舌插入后，抓鳍弯曲并均匀施压，提供自动定心和可调松紧度。

### 双向锁定卡舌 (Bi-directional Locking Tabs)

纯 3D 打印专属——内部有两个凹槽 + 对应两个锁定凸起，插入时凸起弹性弯曲，到位后卡入凹槽。Slant 3D 称之为"把前面所有方法打包在一起的最优解"：
- 首层极简（斜面底→无支撑可打印）
- 双向可拆（适合建筑套件）
- 也可设计为单向永久锁定
- 材料用量最少
- "这是以前从来不可能的设计。" [^1]

## 粘接增强：胶水释放槽

在粘合面上设计内部底切凹腔（数百个小孔，口小肚大）。胶水流入后不仅表面粘附，还形成机械咬合——"胶水嵌入零件内部，抓力远超纯表面粘附。"

辅助技巧：在模型上直接设计胶水涂布区域的纹理标记——"生产中人们就知道胶涂在哪里、涂多少，减少装配错误。" [^1]

## 选择指南

| 需求 | 推荐方法 |
|---|---|
| 最简单、配合胶水 | 菱形销钉 |
| 薄壁边缘、低矮型 | 板槽 |
| 最紧、最精确、零间隙 | 弹簧 T 槽 或 S 型卡扣 |
| 设计最快 | I 型槽 |
| 可调松紧、自动居中 | 抓鳍 |
| 最可靠、易组装、量产品质 | 双向锁定卡舌 |
