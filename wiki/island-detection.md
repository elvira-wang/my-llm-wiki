# 孤岛检测 (Island Detection)

## 定义

孤岛（Island）是切片中某一层里，一块固化区域与下方既没有连接——没有连接到已打印的前一层、也没有连接到支撑、也没有连接到构建平台。"孤岛"意味着这块区域试图在液态树脂中凭空固化，物理上不可能。

**直觉**：想象你用积木从下往上搭塔。如果某一层突然有一块积木悬在半空、下面什么都没有，这块积木就是孤岛——它会掉下去。光固化打印同理，只不过"掉下去"的结果是固化到 FEP 膜上变成一坨垃圾。

**上位概念**：[[print-orientation-resin|打印角度]]——角度是孤岛的根源。好角度能消灭大部分孤岛。

**下位概念**：[[support-structures-resin|支撑]]——检测到孤岛后，唯一解决方案是加支撑。

---

## 孤岛导致的问题

> 模型几何 + 打印角度 → 某层出现孤立截面 → 该区域下方无附着 → UV 照射时树脂固化 → 固化到 FEP 上而非模型上 → 形成一层硬化块粘在膜上 → 下一层平台下降 → 可能将固化垃圾压入 FEP → 刺穿 FEP（Dream Reich 警告 [^1]）→ 整板报废 + 可能损坏机器

并非每个孤岛都会导致整板失败。孤岛的危害取决于它的尺寸和位置：
- **大孤岛**：大面积固化在 FEP 上 → 离型时撕裂膜或扯下模型 → 整板失败
- **小孤岛**（如针尖大的孤立点）：可能只形成一个漂浮的碎屑 → 不一定会毁掉整板，但会在模型表面留下缺陷或混入树脂
- **累积孤岛**：多个小孤岛的碎屑在树脂中积累 → 刮伤 FEP → 慢性损坏

VogMan 描述了大孤岛的情况："它没有连接到平台，当然不可能粘到空气上——所以它只能在 FEP 上形成一个丑陋的硬化块。" [^2]

## 检测方法

### 工具 1：CHITUBOX 内置孤岛检测

- **位置**：切片预览界面，点击"眼睛"图标（Island Detector）
- **颜色含义**：红色/粉色区域 = 检测到需要支撑的问题区域
- **注意**：这个检测不是 100% 可靠的（VogMan 使用 v1.7.0 时指出 [^2]），复杂几何体可能有漏检

### 工具 2：滑块逐层检查（最可靠）

这是 VogMan 和 Dream Reich 都使用的方法 [^1][^2]：

1. 切片完成后，打开切片预览
2. 使用右侧滑块从底层到顶层**逐层拖动**
3. 每一层检查：有没有孤立的白色区域（固化区），下方对应位置在前一层是空白？
4. **旋转视角 360° 逐面检查**——"换一个角度就能看到更多孤岛" [^2]

> **VogMan 的口诀**："如果你看到一个区域的下方没有任何东西——那一块就是孤岛，必须加支撑。"

### 工具 3：自动支撑生成（辅助检测）

CHITUBOX 的自动支撑功能会自动在检测到的孤岛位置加支撑。但 VogMan 明确警告："没有自动支撑是完美的，所以理解 WHY 我们为什么需要这些支撑，才能让我们做得比 AutoSupport 更好。" [^2] Dream Reich 使用自动支撑后仍手动排除残留孤岛："检测到 2 个孤岛，我全部排除。" [^1]

## 孤岛的常见位置

| 位置 | 为什么容易出孤岛 |
|---|---|
| 角色披风的下缘 | 悬空且远离主体 |
| 手臂/武器的末端 | 最外端没有下层支撑 |
| 凸起的装饰物（耳朵、角、手指） | 最突出点下方为空 |
| [[hollowing|镂空]]后的内部悬空 | 内部几何体也可能产生孤岛 |
| 孔洞/镂空区域的顶部 | 桥形结构的顶部第一层 |

---

## 检测的局限

- CHITUBOX 的颜色标记是**启发式算法**——复杂几何体可能漏标（假阴性），也可能在不必要的区域标红（假阳性）
- 孤岛检测不区分"需要支撑的孤岛"和"可以自支持的微小悬空"——颜色标红了不代表一定要支撑
- 镂空后的内部孤岛肉眼不易看到，需要切开预览或依赖软件检测

---

## 延伸方向

- [[print-orientation-resin|打印角度]]：减少孤岛的根本手段——不是检测后补救，而是通过角度消除孤岛
- [[support-structures-resin|支撑]]：检测到孤岛后的唯一解决方案
- [[hollowing|镂空]]：镂空操作可能引入新的内部孤岛
