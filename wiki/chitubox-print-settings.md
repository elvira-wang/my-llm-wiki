# CHITUBOX 打印参数

CHITUBOX [设定] > [打印] 面板中每个参数的逐项说明、设错的后果和推荐范围。以 柚P 的完整解说 [^1] 为主要依据，辅以 Dream Reich [^2] 和 Okay Hobby Time [^3] 的实践经验。

---

## 左侧参数：树脂与曝光

### 层高 (Layer Height)

单层固化厚度。

| 设置 | 效果 | Z 向层纹 | 打印时间 |
|---|---|---|---|
| 小（0.02mm） | 细腻 | 不明显 | 大幅延长 |
| 标准（0.05mm） | 均衡 | 可接受 | 正常 |
| 大（0.10mm） | 粗糙 | 明显 | 最短 |

柚P："没有特殊要求的话，0.05mm 固定就好。用熟了再按场景在 0.02-0.10mm 之间调整。" [^1]

### 底层数 (Bottom Layer Count)

以底层曝光参数打印的初始层数。**建议 1-5 层。**

设多了的后果：打印时间无谓拉长、模型难拆、Raft 易裂。柚P 提醒底层和普通层是分开设置曝光的——底层数只管"用几层底层曝光"，底层曝光时间才是管附着力的关键。[^1]

### 曝光时间 (Exposure Time)

正常层每层的 UV 照射秒数。这是**因树脂和打印机差异最大**的参数——不同品牌/颜色的树脂需要的曝光不同。

起点：树脂厂商官网或包装上的推荐值。目标：通过 [[exposure-calibration|曝光校准]] 精确测定。

Dream Reich 的案例：Elegoo 标准灰 + Saturn 3 Ultra → 从 2.0s 起点测到 1.9s 最佳。[^2]

**设错的后果**：
- 过高：细节糊掉、尺寸偏大、支撑难拆
- 过低：层间附着不足、模型中途脱落、细节模糊

### 底层曝光时间 (Bottom Exposure Time)

初始层的 UV 照射秒数。**通常 30-60s。**

目标不在"一个固定值"——而在于一个平衡：打印时牢固不脱 + 拆模时不费力。Dream Reich 最终值 22s（Saturn 3 Ultra + 标准树脂），在 30-60s 区间以下——"我的机器上 22s 够了，你的可能不一样，因为它取决于 LCD 的光强和你的树脂。" [^2]

详见 [[bottom-exposure|底层曝光]]。

### 过渡层数 (Transition Layer Count)

从底层曝光渐降到正常曝光中间经过的层数。**建议 0-10 层。**

柚P 的示例：底层 30s，正常 2s，过渡层 6 → 每层减 4s：30s → 26s → 22s → 18s → 14s → 10s → 6s → 2s（正常层开始）。[^1]

过渡层减少了底层到正常层之间"突然从 30 秒跳到 2 秒"的附着失败风险。0 = 不使用过渡。

### 打印中待机模式 (Wait Mode)

- **待机时间**（推荐给大多数人）：直接指定等待秒数，简单直观
- **消灯延迟**（上級者向け）：综合平台移动时间调整 UV 时机，逻辑复杂

柚P："以前只有消灯延迟，逼着用它。现在有等待时间了，用等待时间。" [^1]

### 三段待机时间

这是 CHITUBOX 设置中被新手忽视最多、但对打印质量影响最大的参数组。三段时间控制着树脂流动和 UV 照射之间的时序关系。

| 参数 | 时刻 | 推荐值 |
|---|---|---|
| **抬升前待机** | UV 刚灭、平台上升前 | 0.5-2.0s |
| **抬升后待机** | 平台升到顶、即将下降前 | 0.5-1.0s |
| **回降后待机** | 平台降到最低、UV 即将照射前 | 普通粘度 1-2s / 高粘度 3-6s / 低粘度 0.5-1s |

**回降后待机是最关键的一段。** 原因：平台降到最低后，平台与 FEP 之间的间隙只有层高那么宽（如 0.05mm）。树脂被挤压进这个缝隙时仍在流动。如果树脂还在流动中 UV 就照射 → 表面粗糙、固化异常。必须等树脂流动停止后再开 UV。

柚P 按树脂粘度分级：
- 普通粘度树脂 → 1.0-2.0s
- 高粘度树脂 → 3.0-6.0s（流动慢，需要更长时间停止）
- 低粘度树脂 → 0.5-1.0s [^1]

抬升前待机：UV 灭了但化学反应还在继续 → 短等让反应彻底结束再剥离 → 柚P 的经验是影响不大，"我一般设 0.5s"。[^1]

## 右侧参数：Z 轴运动

所有距离和速度参数支持**二段式设定**（两个输入框）。原理：第一段用低速安全剥离 → 第二段用高速跑完行程。如果不想二段式，右边填 0 即可。

柚P 的二段式策略："前段慢剥，后段快跑。一开始用低速把模型从 FEP 安全撕下来，撕开后用高速冲到底，省时间。"

### 距离参数

| 参数 | 适用层 | 柚P 推荐 |
|---|---|---|
| 底层抬升距离 | 初始层平台上升 | 3 + 4 mm |
| 抬升高度 (Lift Distance) | 正常层平台上升 | 2 + 5 mm |
| 底层回退距离 | 初始层平台下降 | 自动 + 1 mm |
| 回退距离 (Retract Distance) | 正常层平台下降 | 自动 + 1 mm |

平台不需要升太高——只要能确保当前层完全脱离 FEP 即可。过高的抬升距离只会浪费打印时间。

### 速度参数

| 参数 | 适用层 | 柚P 推荐 |
|---|---|---|
| 底层抬升速度 | 初始层上升 | 80 + 200 mm/min |
| 抬升速度 (Lift Speed) | 正常层上升 | 80 + 200 mm/min |
| 底层回退速度 | 初始层下降 | 200 + 80 mm/min |
| 回退速度 (Retract Speed) | 正常层下降 | 200 + 80 mm/min |

**速度与距离的二段式联动**：第一段（前框）对应第一段距离，第二段（后框）对应第二段距离。柚P 推荐抬升时前段 80mm/min 慢剥 + 后段 200mm/min 快跑；回退时反过来——前段 200mm/min 快降到接近液面 + 后段 80mm/min 慢入避免产生气泡。[^1]

## 进阶参数

Dream Reich 和柚P 一致的观点：进阶参数（Advanced）不需要动。"我从来不改这里面的东西。" [^2] 除非你有具体的测试需求（如 Dream Reich 的曝光测试将底层数临时改为 1），否则保持默认。

---

## 参数之间的依赖关系

| 参数组合 | 关系 |
|---|---|
| 底层数 + 底层曝光时间 | 底层数管"多少层"，底层曝光管"每层多久"——同时影响附着力 |
| 过渡层数 + 底层曝光时间 + 正常曝光时间 | 过渡层通过三者的差值自动计算每层的减少量 |
| 抬升距离 + 抬升速度（二段式） | 前段距 + 前段速 → 剥离 / 后段距 + 后段速 → 跑行程 |
| 回退距离 + 回退速度（二段式） | 前段距 + 前段速 → 快接近 / 后段距 + 后段速 → 慢入 |
| 回降后待机 + 树脂粘度 | 高粘度树脂需要更长待机 |
