# 后处理

## 定义

光固化打印完成后，将模型从含未固化树脂的状态处理为安全可触摸成品的过程。包含清洗、去支撑、固化、组装四个阶段。

**前置知识**：[[support-structures-resin|支撑]]（拆除支撑是后处理第一步）。工作环境安全（见下文安全部分）。

---

## 全流程

### 1. 取下模型

从打印机取出构建平台。用刮刀或刀片刮刀（比金属刮刀更薄，更易滑入模型底部）取下模型。

Okay Hobby Time 的建议：如果发现用普通金属刮刀难取，换成刀片刮刀（razor blade scraper）——"更锋利，容易滑到模型下面，一撬就下来。至少也能给大刮刀做个突破口。" [^1]

全程戴丁腈手套——此时模型上还有未固化树脂。

### 2. 清洗

用 **99% 异丙醇 (IPA)** 或专用清洗剂去除表面未固化树脂。水和肥皂对树脂无效。

**推荐方案**：清洗固化一体机（Wash & Cure Station）。Okay Hobby Time 的用法与其他人的关键区别——**把整个平台（含模型）直接放进清洗篮**，而不是先取下模型再丢进去。

这样做的好处：
- 避免接触未固化模型——不用弄脏手套
- 同时清洗平台——省一次单独清理
- 小零件不会被冲走（仍然固定在平台上）

前提：清洗机必须能容纳整个平台 + 液态 IPA 要加够（加到能浸没平台和模型的高度）。

**两段式清洗**（可选，效果更好）：

> 脏 IPA 预洗 → 干净 IPA 终洗

两个容器分开——脏桶做粗洗，干净桶做精洗。这样延长干净 IPA 的寿命。

**清洗时间**：Okay Hobby Time 洗约 5 分钟。不需要精确计时——"这个时长够把所有未固化树脂洗掉。" [^1]

**洗后晾干**：放在硅胶垫上铺纸巾，自然晾干几分钟。必须**完全干燥**才能进入下一步。

### 3. 去支撑

两种策略，各有优劣：

| | 固化前去支撑 | 固化后去支撑 |
|---|---|---|
| 难度 | 支撑更软，易拆除 | 支撑硬化，更费力 |
| 安全 | 需戴手套（模型未固化） | 可直接裸手操作 |
| 损伤风险 | 薄件（细武器）易在拆除时断裂 | **热水浸泡软化后再拆**——"几乎消除了固化后拆支撑的差别" [^1] |
| 废弃物 | 未固化支撑 → 有害垃圾 | 固化后支撑 → 普通垃圾 |

精细部件（薄武器、细发、小装饰）用剪钳，不要手撕——手撕会扯掉模型表面。

### 4. 固化

UV 固化灯或 Wash & Cure Station 的固化模式。Okay Hobby Time 的时间建议 [^1]：

- 小模型（标准微缩模型尺寸）：约 **2 分钟**
- 大模型（厚壁、大型雕像）：适当延长，约 **5-20 分钟**
- 过度固化 → 模型变脆

**各面均匀受光**——翻转模型或使用带旋转台的固化站。

## 安全与环境

VogMan 从零基础的视角强调了被高级用户常常忽略的事项 [^2]：

| 事项 | 说明 |
|---|---|
| 丁腈手套 | 全程佩戴。普通乳胶手套会被树脂渗透 |
| 通风 | 开窗 + 空气净化器（HEPA 滤网）。树脂烟雾的长期影响尚无定论——"一个理智的人应该戴呼吸面罩" |
| 3M 防护口罩 | 封闭空间强烈建议 |
| 硅胶垫 | 铺在工作台上——溅出的树脂好清理 |
| IPA 大量储备 | VogMan "一箱 12 瓶起买"——洗几次就用完一瓶 |
| 废液处理 | 固化后的支撑可扔普通垃圾。未固化的树脂和 IPA 废液按有害废弃物处理 |

**不需要恐慌，但不要忽视**——"树脂打印可以做到一滴树脂都不沾手套。我自己的流程就是——这让打印过程干净到让我愿意一遍又一遍地打。" [^1]

## 组装

树脂件需用 **CA 胶（瞬间胶/超级胶）**——普通塑料模型胶水对树脂无效。

Okay Hobby Time 的两个实用技巧 [^1]：
- 一侧涂胶、另一侧喷 CA 加速剂 → 触碰瞬间固化、零等待——"但你得一放准，因为没有任何调整时间"
- 或者先粘合、手扶定位、再喷加速剂——有调整余裕
