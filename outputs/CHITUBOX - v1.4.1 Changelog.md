# 简体中文

在 CHITUBOX v1.4.1 中，我们新增了 ChituNest 耗材商城板块，提供了更灵活的模型复制模式，也修复了自由切割、带支撑复制和启动页渲染相关问题。

## 🚀 新增功能

- **ChituNest 商城**：新增耗材商城板块，提供包括神说、永昌和及 Chitu Systems 等品牌在内的树脂和配件

## 💫 改进

- **复制模式**：支持计算支撑间距或仅计算模型间距两种复制模式
- **打印机支持**：新增 EvoDent E128、E230

## 🔧 修复

- **自由切割**：修复了榫卯反转后切割异常的问题
- **复制**：修复了带支撑复制时模型预览异常的问题
- **渲染**：修复了启动页渲染初始化失败的问题

# English

In CHITUBOX v1.4.1, we've added a supplies section to the ChituNest store and more flexible model duplication modes. We've also fixed issues with Freeform Cutting, duplicating models with supports, and rendering initialization on the Start page.

## 🚀 New Features

- **ChituNest Store**: Added a supplies section offering resins and accessories from brands including 神说, 永昌和, and Chitu Systems

## 💫 Improvements

- **Duplication Modes**: Added support for two duplication modes that calculate spacing between supports or between models only
- **Printer Support**: Added EvoDent E128 and E230

## 🔧 Fixes

- **Freeform Cutting**: Fixed an issue where cutting produced incorrect results after reversing mortise-and-tenon joints
- **Duplication**: Fixed an issue where model previews displayed incorrectly when duplicating models with supports
- **Rendering**: Fixed an issue where rendering initialization failed on the Start page
