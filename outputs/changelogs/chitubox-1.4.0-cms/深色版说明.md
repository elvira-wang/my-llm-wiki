## 配色

查看官网当前视觉后采用深炭灰、冰蓝与低饱和蓝紫色搭配。这是基于官网视觉的适配，不是已核实的官方色值规范。

| 元素 | 配色 |
|---|---|
| 正文最外层 | `transparent`，直接透出官网的底色 |
| 本地预览模拟站点底色 | `#101114`，仅在预览文件的 body 上设置 |
| 大标题、小标题 | `#f2f5fa` |
| 正文 | `#d5dbe5` |
| 导语 | `#aebdce` |
| 功能编号、补充标题 | `#87caff` |
| 提示框底 / 文字 | `#17222e` / `#c2cedd` |
| 链接 | `#acd6ff` |
| 媒体边框 | 深蓝到低饱和蓝紫渐变，降低光晕强度 |

这里只更改正文组件内部的样式，不修改官网的全局配色。最外层透明底适用于放在官网深色背景之上；若粘贴后仍出现整块白底，应检查公司系统在文章外部添加的白色容器。

## 检查范围

已核对 HTML 标签嵌套、原文内容、媒体 URL、链接保留情况；增加媒体边框层的 `box-sizing: border-box`，使 4px 内边距计入总宽度。桌面 1440px 与手机 390px 的本地布局检查通过，没有水平溢出或元素被裁切。
