# CHITUBOX 1.4.0 博客 CMS 排版源码

## 文件

- `chitubox-1.4.0-zh-hans-cms.txt`：中文正文 HTML，粘贴进公司系统的 HTML / 源代码模式。
- `chitubox-1.4.0-en-cms.txt`：英文正文 HTML，发布到英文文章。
- 两份 `*-preview.html`：浏览器预览文件，当前显示素材占位框。不是已上传的网页。
- 四份 `preview-*.png`：1440px 桌面与 390px 手机宽度的预览截图。

两种语言分别排版，供各语言站点发布；逐段中英对照学习稿保留在上一级目录。

## 使用方式

1. 打开对应语言的 `*-cms.txt`，复制全文到系统的源代码模式。不要粘贴 Markdown 代码围栏，也不要把完整预览 HTML 的 head/body 一并粘贴。
2. 将录屏、GIF 和照片上传到公司素材系统，取得可直接访问的媒体文件 URL。
3. 在代码中搜索 `BEGIN_MEDIA_01_PLACEHOLDER` 到 `END_MEDIA_01_PLACEHOLDER`，将两者之间的占位 `div` 整段换成媒体标签。
4. 依次替换 01—06 共六处。每处前面的注释都附有 GIF/照片标签，前五处还附有 MP4 录屏标签；复制其中一种，替换 `REPLACE_MEDIA_XX_URL` 即可。复制出来的标签要放在注释之外才会显示。
5. 保存为草稿，在公司系统中预览一次，再发布。当前已在本地 Chromium 检查桌面和手机宽度，未进入公司 CMS 验证其 HTML 清洗或站点样式。

| 标记 | 素材内容 | 建议展示的动作 |
|---|---|---|
| MEDIA_01 | 拆件录屏 / GIF | 智能分色 → 调整区域 → 拆分结果 |
| MEDIA_02 | 图片标签录屏 / GIF | 导入灰度图 → 阳刻/阴刻 → 翻转 |
| MEDIA_03 | Z 轴复制录屏 / GIF | 复制选项 → 纵向排列 → 调整保护框架 |
| MEDIA_04 | 自由切割录屏 / GIF | 多切割面 → 路径光滑 → 榫卯自适应 |
| MEDIA_05 | 悬空检测录屏 / GIF | 黄色转水蓝色 → 紫色标记 → 筛选 |
| MEDIA_06 | 结尾成品照片 | 保留模型主体完整，不强制裁为 16:9 |

前五段优先使用能看清界面文字的录屏，当前占位比例为 16:9；替换后的图片或视频会按原始比例显示，不强制拉伸或裁切。最后的照片占位为 4:3，实际照片同样按原始比例显示。

## 替换示例

GIF 或照片：

```html
<img src="这里放上传后的GIF或照片URL"
     alt="这里填写图片内容，例如：按分色区域拆分模型"
     loading="lazy"
     style="display: block; width: 100%; max-width: 100%; height: auto; border-radius: 14px;">
```

MP4 录屏：

```html
<video controls="controls" playsinline="playsinline" preload="metadata"
       style="display: block; width: 100%; max-width: 100%; height: auto; border-radius: 14px;">
  <source src="这里放上传后的MP4文件URL" type="video/mp4">
  您的浏览器不支持视频，请使用支持 HTML5 视频的浏览器。
</video>
```

英文版的替换素材请填写英文替代文字。视频默认点击播放，保留控制条；若要静音循环演示，可使用 `autoplay muted loop playsinline`，但浏览器仍可能限制自动播放。

## 与参考排版的对应关系

保留蓝色渐变、发光圆角媒体框、桌面左右交错和居中导语；全部正式样式都写在元素内，不依赖脚本、外链字体或独立样式表。

改用自然页面滚动，去掉固定视口背景和 `100vh` 内部滚动；媒体自适应宽度，窄屏按“标题与文字 → 演示素材”顺序上下排列。模型质量等提示使用较轻的蓝色提示块。

当前源码包含正文标题。如果系统会自动在正文上方显示相同文章标题，可在源码中删除这一处 `<h1>…</h1>`，避免重复显示。
