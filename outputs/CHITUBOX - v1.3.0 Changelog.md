# 简体中文

CHITUBOX v1.3.0 正式发布！本次更新带来自由切割、模型封装和快速对齐工具，助您轻松驾驭各种复杂模型。功能面板和对话框全面开放快捷键支持，界面布局随心自定。欢迎立即下载，探索更多高效新特性！

## 新增功能

- **自由切割**：在模型表面自由绘制切割路径，闭合形成切割面，锚点可灵活调节
- **封装模型**：将多个模型封装为单一对象，并为其生成包围盒
- **模型对齐**：通过面对齐或线对齐，快速将两个模型旋转放置到理想位置
- **功能面板快捷键**：常用按钮现已支持快捷键显示与触发
- **对话窗口快捷键**：可通过键盘快速触发对话窗口中的命令按钮
- **顶部功能栏快捷键**：短按 `Alt` 键，临时显示顶部功能栏全部快捷键

## 改进

- **模型布局模式**：导入、复制、镜像模型时均可应用“在当前平台居中”、”应用自动布局”、“保留原始世界坐标”
- **对象旋转**：按住 `Shift` 以 45° 增量旋转，按住 `Shift + Ctrl` 以 15° 增量旋转
- **平台菜单**：新增展开/收起全部选项
- **材料参数配置**：支持批量删除材料参数
- **修复**：高级修复已归入模型修复子项
- **快捷键**：新增 3D 视图控制快捷键
- **自定义面板布局**：支持左右双面板、单面板（合并至右侧）、单面板（合并至左侧）三种布局
- **ChituAction**：齿科工作区下，所有应用可选配置扩展至 3 个
- **交互体验**：优化了模型与对象列表的交互体验
- **镜像支撑**：提升了镜像支撑检测精度
- **布尔操作**：优化了布尔操作性能
- **缩略图**：提升了缩略图分辨率
- **格式支持**：新增 `.prz` 与 `.goo` 格式桌面预览
- **打印机**：新增 Phrozen Sonic Mighty Revo 16K Max、ELEGOO Jupiter 2

## 修复

- **自动支撑**：修复了支撑重复添加的问题
- **框选**：修复了模型重叠时无法全部框选的问题
- **布尔操作**：修复了布尔操作结果错误的问题
- **底筏**：修复了部分底筏添加异常的问题
- **稳定性**：修复了一些已知問題

# 繁體中文

CHITUBOX v1.3.0 正式發佈！本次更新帶來自由切割、模型封裝和快速對齊工具，助你輕鬆駕馭各種複雜模型。功能面板與對話視窗全面開放快捷鍵支援，界面佈局隨心自訂。歡迎立即下載，探索更多高效新特性！

- **自由切割**：在模型表面自由繪製切割路徑，閉合後即形成切割面，並可靈活調節路徑錨點位置，使切割結果更精確；
- **封裝模型**：將多個模型封裝為單一對象，並為其生成包圍盒

- **模型佈局模式**：導入、複製、鏡像模型時均可選擇「在當前平台居中」「應用自動佈局」「保留原始世界坐標」

- **快捷鍵**：新增 3D 視圖控制快捷鍵
- **自定義面板佈局**：支援左右雙面板、單面板（合併至右側）、單面板（合併至左側）三種佈局
- **ChituAction**：齒科工作區下，所有應用可選配置擴展至 3 個
- **互動體驗**：優化了模型與對象列表的互動體驗
- **鏡像支撐**：提升了鏡像支撐檢測精度
- **布林運算**：優化了布林運算操作性能
- **縮略圖**：提升了縮略圖解析度
- **格式支援**：新增 `.prz` 與 `.goo` 格式桌面預覽
- **印表機**：新增 Phrozen Sonic Mighty Revo 16K Max、ELEGOO Jupiter 2

## 修復

- **自動支撐**：修復了支撐重複添加的問題
- **框選**：修復了模型重疊時無法全部框選的問題
- **布林運算**：修復了布林運算結果錯誤的問題

# English

Welcome to CHITUBOX v1.3.0! This release introduces powerful Free Cutting, Model Combining, and Alignment tools to help you tackle complex models with ease. We’ve also extended shortcut support across all panels and dialogs, and made the panel layout customizable to match your unique workflow. Upgrade now to explore these efficiency-boosting new features!
## New Features

- **Free Cutting**: Draw custom cutting paths directly on the model surface, close them to form a cutting plane, and adjust anchor points flexibly for more precise results
- **Combine Models**: Encapsulate multiple models into a single object and generate a bounding box for the group
- **Model Alignment**: Quickly rotate and position two models using Face Alignment or Line Alignment
- **Panel Shortcuts**: Common buttons now display and respond to keyboard shortcuts
- **Dialog Shortcuts**: Command buttons in dialogs can now be triggered via keyboard
- **Toolbar Shortcuts**: Briefly press `Alt` to temporarily reveal all top toolbar shortcuts

## Improvements

- **Model Layout Strategy**: "Center on Platform", "Auto Layout", and "Preserve Original World Coordinates" can now be applied when importing, duplicating, and mirroring models
- **Object Rotation**: Hold `Shift` to snap to 45° increments; hold `Shift + Ctrl` to snap to 15° increments
- **Platform Menu**: Added Expand/Collapse All options
- **Material Profiles**: Support for batch deleting material parameters
- **Repair**: Advanced Repair is now a sub-item under Model Repair
- **Shortcuts**: Added new shortcuts for 3D view control
- **Custom Panel Layout**: Choose from Dual Panels (Left & Right), Single Panel (Merged to Right), or Single Panel (Merged to Left)
- **ChituAction**: In Dental Workspace, optional configurations for all applications expanded to three
- **Interaction**: Improved the Model and Object list interaction experience
- **Mirrored Supports**: Enhanced detection precision for mirrored supports
- **Boolean Operations**: Optimized Boolean operation performance
- **Thumbnails**: Improved thumbnail resolution
- **Format Support**: Added desktop preview for `.prz` and `.goo` formats
- **Printers**: Added Phrozen Sonic Mighty Revo 16K Max and ELEGOO Jupiter 2

## Fixes

- **Auto Supports**: Fixed an issue where supports were being added repeatedly
- **Box Selection**: Fixed overlapping models not being fully selectable via box selection
- **Boolean Operations**: Fixed incorrect results in certain Boolean operations
- **Rafts**: Fixed an issue where rafts were generated incorrectly in some cases
- **Stability**: Fixed various known issues
