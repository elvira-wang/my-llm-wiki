# 简体中文

CHITUBOX v1.3.1 新增打印机支持与机器参数更新，精进模型对齐、窗口状态记忆和切片放大镜预览效果，让您的日常切片流程更加顺畅。
## 改进

- **打印机支持**：新增 Anycubic Photon P1 Max、HALOT-X1 Neo
- **机器参数**：调整了部分机器参数
- **模型对齐**：优化了模型对齐效果
- **窗口状态**：支持记忆软件全屏化/窗口化状态
- **切片放大镜**：优化了非方块像素放大镜预览效果

## 修复

- **稳定性**：修复了一些已知问题

# English

CHITUBOX v1.3.1 brings new printer support and machine parameter updates, along with refinements to model alignment, window state memory, and Slice Magnifier previews for a smoother daily slicing workflow.

## Improvements

- **Printer Support**: Added Anycubic Photon P1 Max and HALOT-X1 Neo
- **Machine Parameters**: Adjusted parameters for certain machines
- **Model Alignment**: Improved alignment results
- **Window State**: Added memory for fullscreen and windowed states
- **Slice Magnifier**: Improved preview behavior for non-square pixels

## Fixes

- **Stability**: Fixed known issues
